# 손실된 렌더 기대값으로 표·링크·개행의 표시 품질을 검수하지 않는다

## 적용 범위와 비적용 조건

원고 정본을 UI 입력으로 바꾸고 실제 표시 결과를 검증하는 변환·초안 파이프라인에 적용한다. 네이버 노출 기준이나 사실성 검수, 라이브 브라우저 호환성의 보증은 아니다.

## 관측 사실과 영향

기존 render plan이 table을 레이블 문단으로 바꾸고, 링크를 전체 URL이 보이는 문자열로 펼쳤다. 공백 정규화 검사에는 실제 개행을 공백으로 합친 관찰도 통과했다. 독립 synthetic fixture 재현에서 네이티브 표와 문단 간격이 사라져도 기존 검수가 passed였음을 확인했다. 기존 원고와 이벤트는 읽기만 했다.

## 근본 원인·기여 요인·근거

정본의 표현 의도 대신 이미 손실된 renderer 출력을 기대값으로 사용했다. 문자열과 이미지 개수 중심의 대조에는 native 행·열, 실제 href, 명시 개행과 문단 여백의 관찰 계약이 없었다. 조사 지침의 근접 링크 기본값도 개인 프로필의 말미 출처 기본값과 충돌했다. 원인 확신은 confirmed이며 기존 스크립트 경로·독립 fixture 재현을 근거로 한다.

## 해결과 예방 control

네이티브 table step과 클릭형 link mark, 원고 개행을 보존한다. 표 평문 대체를 금지하고 지원 불가 또는 미관찰은 실패/unknown으로 중단한다. 현재 render policy를 revision과 입력·재열기·다음 회차 게이트에 연결한다. 실제 table/href/BR/빈 문단 또는 양수 간격 근거를 별도 검사한다. 출처를 말미로 모으되 이번 명시 요청을 우선하고 중복·전체 URL 노출을 preflight에서 진단한다. 구 이벤트는 historical 읽기만 허용하며 새 검수로 승격하지 않는다.

## 검증

2026-10-13: 프로젝트와 설치 패키지의 Python 전체 300건, Node 전체 42건 통과. 독립 fixture는 표 문단 대체, 잘못된 셀/빈 셀/행 순서/병합, href 누락, hard-break 소실, 문단 간격 미관찰, 구 정책 검수 우회를 차단한다. 기존 저장 로그 읽기 회귀와 13편 순차 저장 simulation도 포함한다. 실제 네이버 계정은 실행하지 않았다.

## 발생 정보

OCC-20261013-PRESENTATION-QA. 개발 계획의 선행 분석 및 손실형 fixture 재현에서 발견한 표시 검수 escape. 임시 조치는 기존 산출물 보존, 순수 재현과 새 정책의 검증 강화다. 원고·이미지·사용자 계정 정보나 원시 로그는 교훈에 포함하지 않는다.

## 검토와 예외

medium/advisory로 분류했다. 정확한 셀과 href/개행/여백을 관찰할 수 있는 UI 도구에서만 새 완료를 보고한다. 사람이 선택한 inline 출처나 의도적인 시리즈 디자인은 존중하지만 자동 평문 표 대체는 허용하지 않는다. 새로운 렌더 정책이나 네이버 UI 변경 시 실제 관찰 계약을 다시 검토한다. 독립 인간 승인으로 간주하지 않는다.
