# 현재 스킬 기능과 사용 예제

기준일: **2026-10-12**. 현재 저장소의 작업 트리와 각 `SKILL.md`를 기준으로 정리했다. 구현된 기능, 이전 검증 기록, 아직 확인하지 않은 실행 환경을 구분한다. 사용자 명시 조건이 기본값보다 우선하며, 세부 계약은 연결된 스킬·reference를 따른다.

## 1. 어떤 스킬을 사용할까?

| 요청 | 스킬 | 결과 |
|---|---|---|
| 주제로 글을 쓰거나 기존 글을 수정 | [naver-blog-style](../SKILL.md) | 저장된 문체를 적용한 단일 원고, 요청 시 이미지 포함 원고 |
| 옵션을 한 질문씩 선택하며 작성 | [naver-blog-wizard](../skills/naver-blog-wizard/SKILL.md) | 확정 원고·이미지 계획·요청한 이미지 패키지와 재개 가능한 세션 |
| 제목만 생성·개선 | [naver-title](../skills/naver-title/SKILL.md) | 검색형·홈판형·혼합형 후보와 추천 |
| 실제 유입을 보고 다음 주제 선정 | [naver-creator-keyword-recommender](../skills/naver-creator-keyword-recommender/SKILL.md) | 추천 키워드·대표 제목·집계 패턴·수집 상태 |
| 연재를 기획하고 한 편씩 작성 | [seo-series-writer](../skills/seo-series-writer/SKILL.md) | 전체 목차와 요청한 회차 원고 |
| 여러 편의 원고·이미지 패키지 준비 | [naver-series-workflow](../skills/naver-series-workflow/SKILL.md) | 검수 상태와 네이버 입력용 준비 패키지 |
| 완성 원고를 네이버에 입력·임시저장 | [naver-smarteditor-drafter](../skills/naver-smarteditor-drafter/SKILL.md) | 사전검증 또는 입력·저장·재열기 확인 기록 |

저장소를 작업 폴더로 사용하면 해당 스킬 파일을 직접 읽도록 요청한다.

```text
이 저장소의 SKILL.md를 읽고 네이버 블로그 스킬을 적용해줘.
주제: 일본 여행 전 준비할 결제수단.
초보 여행자를 위한 비교형 글로 작성해줘.
```

아래의 `$스킬명` 예제는 설치·등록된 환경 기준이다. 폴더나 `agents/openai.yaml`이 존재하는 것만으로 전역 설치·자동 선택 성공을 의미하지 않는다. 문답형과 공통 이미지 도우미를 쓰는 흐름은 저장소의 공통 파일·sibling 스킬을 참조하므로 하위 스킬 폴더만 복사해 독립 실행된다고 안내하지 않는다.

## 2. 기본값과 적용 범위

| 항목 | 현재 기본값 | 적용 조건 |
|---|---|---|
| 저장된 문체 | [스타일 프로필](naver-blog-style-profile.md) 적용 | 기본 단일 글 작성. 문체 인터뷰는 요청 시 시작 |
| 기존 블로그 본문 참고 | 블로그 서비스 검색에서 고유 본문 5개 | 새 정보형·방법형·비교형 글. 지정 가능한 참고 수는 1~8개 |
| 통합 작성 제목 | 검색형·홈판형·혼합형 각 3개 내부 비교 → 혼합형 최종 1개 | 기본 글쓰기 흐름. 고정 제목·명시 유형·개수 우선 |
| 일반 제목 전용 요청 | 검색형 5개·홈판형 5개·혼합형 3개 | 유형·개수가 없는 일반 `naver-title` 요청 |
| 제목 단축 요청 | 검색형 4개·홈판형 3개·혼합형 3개 + 최종 추천 | `네이버 제목/타이틀/주제 …` |
| 이미지 없는 글 | 이미지 생성 생략 | 글 작성만 요청 |
| 이미지 포함 단일 글 | 표지 포함 총 5장 | 이미지 포함을 요청하고 장수는 생략한 경우. 명시 N은 정확히 N장 |
| 문답형 이미지 자동 장수 | 추천 5장을 질문에서 확인 후 적용 | 문답형의 미응답·기본 선택은 확정 답변이 아님 |
| 카드뉴스 비율 | 4:5, 권장 1080×1350 | 실제 반환 크기를 검사하며 권장 픽셀과 동일한 결과를 보장하지 않음 |
| 연재 편수 | 15편 | 편수·목차·작성 범위 지정 시 그 조건 우선 |
| 완성형 연재 본문 | 편당 최소 3,000자 | 제목·태그·참고 URL·이미지 정보·편집 메모 제외 |
| 이미지 필수 연재 | 표지 1장 + 본문 2장 이상, 총 최소 3장 | 전문가형 미지정 목표는 5장. 다른 프로필의 기존 목표 유지 |
| 유입 분석 기간 | 오늘 제외 최근 완료 7일과 이전 7일 비교 | 사용자 지정 기간 우선 |
| 네이버 입력 | `prepare`로 로컬 사전검증 | 실제 입력·임시저장은 명시 요청 시 `draft` |

**참고 글 5개·이미지 5장·제목 후보 5개는 각각 독립된 조건이다.** 시리즈의 15편·3,000자·이미지 최소 3장을 단일 글에 적용하지 않는다. 제목의 혼합형과 이미지의 혼합형도 별개다.

## 3. 단일 글 작성·재작성·문체

[naver-blog-style](../SKILL.md)은 주제와 독자 의도에 맞는 원고를 작성하고 저장된 문체를 적용한다. 기존 글은 요청 범위대로 다듬으며, 다른 작성자의 경험을 자신의 경험으로 만들지 않는다.

```text
$naver-blog-style
주제: 일본 여행 전 준비할 결제수단.
초보 여행자를 대상으로 장단점과 선택 기준을 비교해 작성해줘.
제목은 검색형으로 선정해줘.
```

```text
이 원고를 네이버 블로그 스킬로 재작성해줘.
핵심 내용은 유지하고, 긴 문단과 중복 설명을 정리해줘.
검색 보완은 하지 마.
```

문체 프로필을 새로 정할 때는 7개 차원의 선택형 인터뷰를 사용한다. 한 질문씩 진행하고 말투·리듬·근거·구성을 `always / usually / optional / avoid` 규칙으로 정리한다.

```text
내 네이버 블로그 문체를 설정해줘.
선택지를 한 질문씩 보여주고, 확정한 내용을 스타일 프로필로 정리해줘.
```

## 4. 기존 네이버 블로그 본문 참고

새 정보형·방법형·비교형 원고의 기본 참고는 실제 기존 본문 5개다. 검색 요약만으로 본문을 읽었다고 처리하지 않고, 공통 검색 의도·내용·빠진 정보를 분석한 뒤 공식 자료로 사실을 확인한다. 반복 언급만으로 인기 순위나 특정 국적의 구매 비중을 확정하지 않는다.

```text
돈키호테 쇼핑리스트를 카테고리별로 작성해줘.
기존 네이버 블로그 본문 3개를 참고하고 제품 정보는 공식 자료로 확인해줘.
정보 슬라이드 5장을 생성해 본문에 삽입해줘.
```

```text
네이버 검색 결과의 블로그 본문 5개를 참고해서
오사카 여행 준비 글을 작성해줘.
```

```text
기존 블로그 글은 참고하지 말고 제공한 자료만으로 작성해줘.
```

미지정은 블로그 서비스 검색이고, `네이버 검색 결과를 참고`는 통합 블로그 검색이다. 재작성에는 검색 보완을 요청한 경우에만 적용한다. 개인 경험 후기·일기·문체 인터뷰는 명시 참고 요청이 있어야 적용하고, 제목만·이미지만 요청하면 본문 조사를 생략한다.

명시 N개 중 유효 본문이 부족하면 해당 참고 조건은 미충족이다. 기본 5개에서 일부만 확보했으면 실제 확보 수·누락·잘린 문맥을 밝히고 그 범위로 작성할 수 있다. 이 공통 참고 단계의 현재 연결 대상은 루트와 문답형의 단일 글 작성이며, 모든 연재에 자동 적용된 기능으로 설명하지 않는다.

세부 규칙: [수집·분석 흐름](../references/blog-research-workflow.md) · [입출력 계약](../references/blog-research-contract.md).

## 5. 이미지 계획·생성·삽입·편집

이미지 슬롯은 확정 제목·인접 본문·설명 목적에 맞춰 정한다. 장면·구도·매체를 선택하고 본문 근거에서 카드 제목·요점을 추출해 장별 프롬프트를 조립한다.

| 표현 유형 | 구성 |
|---|---|
| 일반형 `standard` | 문맥에 맞는 사진·일러스트·도해 |
| 정보 슬라이드형 `info-slide` | 표지를 포함한 모든 장을 카드뉴스로 구성 |
| 혼합형 `mixed` | 일반형 표지 1장 + 정보 슬라이드 N−1장 |

| 작업 모드 | 결과 |
|---|---|
| `plan-only` | 슬롯·스토리보드·프롬프트만 준비 |
| `generate-and-compose` | 실제 생성 → 시각 검수 → manifest → 본문 삽입 |
| `edit-existing` | 확인한 원본 이미지를 사용해 요청한 부분 편집 |

주제부터 완성하는 예제:

```text
$naver-blog-style
주제: 돈키호테 쇼핑리스트를 과자·식품·뷰티·생활용품으로 정리.
기존 네이버 블로그 본문 5개를 참고하고 공식 자료로 사실을 확인해줘.
검색과 홈판을 함께 고려한 제목을 적용하고,
정보 슬라이드 / 카드뉴스형 5장을 생성해 본문에 삽입해서 완성해줘.
```

계획·기존 원고·편집 예제는 각각 별도 요청이다.

```text
이 원고에 들어갈 카드뉴스 5장의 구성과 프롬프트만 만들어줘.
이미지는 생성하지 마.
```

```text
이 원고의 제목과 본문을 유지하고 혼합형 이미지 5장을 만들어 삽입해줘.
```

```text
제공한 이미지의 배경만 밝게 수정해줘.
제품 형태와 글자는 유지해줘.
```

N장 완성은 현재 원고에 연결된 **승인된 고유 로컬 파일 N장과 삽입 N개**를 모두 요구한다. 계획·파일 경로·미검수 manifest만으로 완료 처리하지 않는다. 실제 생성·글자·관련성·사실성·비율·묶음 차별성 검수와 로컬 패키지 검사는 별개다.

세부 규칙: [주제부터 이미지 포함 완성](../references/topic-image-completion-workflow.md) · [프롬프트 계약](../references/blog-image-prompt-contract.md) · [manifest v1](../references/image-slot-manifest.md).

## 6. 한 질문씩 선택하는 문답형

[naver-blog-wizard](../skills/naver-blog-wizard/SKILL.md)는 새 글·재작성·이미지만 추가·기존 이미지 편집을 선택해 진행한다. 독자·글 유형·말투·분량·서식과 이미지 없음·프롬프트만·생성·내 파일 사용을 확인하고, 새 원고와 이미지 계획의 사용 선택을 받는다.

```text
$naver-blog-wizard
주제는 일본 여행 전 준비할 결제수단이야.
글쓰기와 이미지 옵션을 한 질문씩 선택하게 해줘.
```

```text
이전 세션을 이어서 진행해줘.
원고는 유지하고 이미지 유형만 카드뉴스형으로 변경해줘.
```

이미 제공한 답은 유지하고, 변경한 옵션에 해당하는 원고·계획·승인만 다시 확인한다. 작업 파일과 세션을 사용자 작업 영역에 보관하며, 결과가 불명확한 생성은 실제 반환 파일과 대조한 뒤 복구한다. 이 스킬에서 문체 인터뷰·시리즈·네이버 입력을 시작하지 않는다.

## 7. 검색형·홈판형·혼합형 제목

[naver-title](../skills/naver-title/SKILL.md)은 검색 의도와 독자의 읽을 이유를 구분해 후보를 만든다. 질문형은 선택 가능한 구조이며 모든 제목의 기본 형태가 아니다. 제목과 본문, 숫자·경험·순위 근거를 대조한다.

```text
네이버 제목 돈키호테 쇼핑리스트
검색형 3개, 홈판형 3개, 혼합형 3개를 만들고
최종 추천과 선정 이유를 알려줘.
```

```text
$naver-title
이 원고에 맞는 홈판형 제목 5개를 만들어줘.
질문형에 치우치지 말고 선택 기준과 차이가 드러나게 해줘.
```

통합 글쓰기는 최종 제목만 원고에 반영하고 후보·선정 메모를 분리한다. 고정 제목은 유지하며, 기존 글의 이미지 전용 요청으로 제목을 바꾸지 않는다.

## 8. 실제 유입 기반 주제·대표 제목 추천

[naver-creator-keyword-recommender](../skills/naver-creator-keyword-recommender/SKILL.md)는 로그인된 크리에이터 어드바이저의 실제 화면을 관찰한다. 검색 유입으로 주제를 정하고 메인 유입으로 제목 패턴을 분석한다. 요청하면 블로그 홈 1~10페이지의 제목 구조도 별도로 분석한다.

```text
$naver-creator-keyword-recommender
내 블로그 [블로그 주소]의 최근 완료 7일 유입을 이전 7일과 비교해줘.
일본 여행 관련 주제 5개와 각각의 대표 제목을 추천해줘.
```

```text
네이버 블로그 홈 1~10페이지의 제목 패턴만 분석해줘.
원문 제목을 복제하지 말고 활용할 수 있는 구조를 정리해줘.
```

| 모드 | 수행 범위 |
|---|---|
| `recommend` | 기본 키워드 추천 + 키워드별 대표 제목 1개 |
| `keywords-only` | 키워드만 |
| `patterns` | 메인 유입 제목 패턴만 |
| `home-patterns` | 블로그 홈 제목 패턴만 |
| `recommend-with-home` | 유입 키워드 + 메인·홈 집계 패턴으로 대표 제목 보완 |
| `title-candidates` | 추가 제목 후보. 개수 미지정 시 키워드별 3개 |
| `full` | 명시한 산출물만 글·이미지·SmartEditor 흐름으로 연결 |

홈 분석의 제목 표본은 검색 키워드로 바꾸지 않는다. 이 기능의 홈 제목 패턴 분석과 단일 글 작성의 기존 게시물 본문 참고는 서로 다른 수집이다. 실제 관찰 범위·부분 수집을 보고하며 검색량·조회수·CTR을 추측하지 않는다.

## 9. 연재 기획·원고 작성

[seo-series-writer](../skills/seo-series-writer/SKILL.md)는 니치·전체 목차·제1편부터 시작해 요청 범위대로 이어 쓴다. 전문가형·스토리형·후기형·친숙한 설명형·문제 해결형·비교 선택형 프로필을 지원하고, 미지정은 `expert + friendly`다.

```text
$seo-series-writer
일본 자유여행 준비를 주제로 5편의 목차와 제1편을 작성해줘.
각 편은 다른 질문을 해결하고, 완성형 본문은 3,000자 이상으로 작성해줘.
초보자가 따라 할 순서와 예외 조건을 포함해줘.
```

같은 대화에서 `다음 편`, `제3편 재작성`, `발행 패키지`, `상태 요약`을 요청할 수 있다. 파일 출력 요청 시 공개 본문 `article.md`, 편집 메모 `editorial.json`, 검토 대기 `review.json`을 분리한다. 단독 연재 작성은 개인 문체 자동 적용·이미지 생성·네이버 입력을 기본으로 수행하지 않는다.

## 10. 시리즈 원고·이미지 통합 준비

[naver-series-workflow](../skills/naver-series-workflow/SKILL.md)는 작성 → 내용 검수 → 이미지 계획·생성·검수 → 네이버 정본 준비를 연결한다. 이미지 장수를 지정하면 회차별 수량을 검사하고, 이미지 필수 v2의 최소 3장과 충돌하는 요구는 계약 불일치로 보고한다.

```text
$naver-series-workflow
일본 여행 준비 5편을 네이버용으로 작성해줘.
각 편에 카드뉴스형 이미지 5장을 생성해 삽입하고,
prepare 모드로 검수된 원고와 이미지 패키지를 준비해줘.
```

준비된 원고의 내용·길이·구조·시각·입력 준비 상태를 분리한다. 파일 준비 완료는 실제 업로드·저장 성공이 아니다. `draft`, `resume`, `status`를 지원하며 실제 입력은 대상 블로그와 범위를 지정한 요청으로 연결한다.

```text
검수 완료된 시리즈 1~5편을 [블로그 주소]에 순서대로 입력하고,
각 편을 임시저장한 뒤 재열어 확인해줘.
```

## 11. 완성 원고의 SmartEditor 입력·임시저장

[naver-smarteditor-drafter](../skills/naver-smarteditor-drafter/SKILL.md)는 완성 Markdown 또는 구조형 JSON을 `naver-post/v1`으로 검증한다. 실제 이미지 파일·해시·서식·태그를 확인하며 원고나 이미지를 새로 창작하는 역할은 아니다.

| 모드 | 동작 |
|---|---|
| `prepare` | 로컬 사전검증 |
| `draft` | 실제 입력·업로드·임시저장·재열기 확인 |
| `resume` | 실행 이력과 실제 화면 대조 후 재개 |
| `status` | 로컬 실행 이력 조회 |

```text
$naver-smarteditor-drafter
[원고 파일 절대 경로]와 이미지 패키지를 prepare 모드로 검증해줘.
```

```text
검수된 [원고 파일 절대 경로]를 [블로그 주소]에 입력하고
이미지를 업로드한 뒤 임시저장해줘.
저장한 초안을 재열어 제목·본문·이미지 배치를 확인해줘.
```

실행에는 로그인된 브라우저와 대상 블로그, 로컬 파일 업로드·관찰 기능이 필요하다. 한 편씩 빈 화면 → 입력 → 전체 대조 → 저장 응답 → 재열기 대조 → 새 빈 화면을 확인한다. 저장 여부가 불명확하면 다음 편을 진행하지 않는다. 공개·예약 발행은 수행하지 않는다.
