# 상황별 이미지 연출

이미지를 새로 생성하거나 교체할 때 읽는다. 텍스트만 작성하거나 기존 승인 이미지를 그대로 입력하는 작업에는 새 이미지 생성을 추가하지 않는다.

## 핵심 원칙

**이미지는 제목·인접 문단의 문맥·구체적인 상황·분위기·설명 목적에 맞춰 만든다.** 실사, 인포그래픽, 일러스트 중 하나를 모든 글의 기본 형식으로 고정하지 않는다. 문체 프로필은 분위기를 조절하는 입력이지 같은 배경·색·구도를 복제하는 템플릿이 아니다.

사용자가 실사만, 인포그래픽만, 특정 화풍이나 시리즈 공통 스타일을 요청했다면 그 범위 안에서 장면·구도·정보 표현을 선택한다. 다양성을 이유로 명시적 선호를 무시하지 않는다. “주제마다 다르게”도 모든 이미지의 매체를 억지로 바꾸라는 뜻은 아니다.

## 생성 전 판단

1. 전체 제목이 약속한 질문과 이미지가 붙을 문단의 질문을 구분한다. 대표 이미지는 글의 중심 상황을, 본문 이미지는 그 문단의 구체적인 설명을 보완한다.
2. 실제로 보여줄 것이 사람·장소·재질·행동인지, 구조·관계·수량·순서인지 판단한다. 문단을 이해하는 데 무엇이 보이면 도움이 되는지를 먼저 정한다.
3. 상황에 맞는 매체와 연출을 고른다. 실사는 착용·질감·공간, 도해는 원리·절차·비교, 삽화는 생활 맥락·추상 개념 등에 유용하지만 주제별 고정 배정표로 쓰지 않는다.
4. 분위기와 사실성 경계를 맞춘다. 금융 사고를 공포 연출로 과장하거나 생활 선택 글을 공식 공문처럼 만들지 않는다. 정확한 UI·문서·방문 증거가 필요한 경우 생성 그림으로 대체하지 않는다.
5. 회차별 시각 브리프와 슬롯별 선택 이유를 편집 메모 또는 별도 시각 계획에 남긴다. 제목, 인접 문단, 독자가 얻는 정보, 매체, 장면, 구도·화면비, 분위기, 금지 요소를 포함하되 관리 내용을 게시 본문에 넣지 않는다.

매체와 형식은 구분한다. 예를 들어 인포그래픽도 경로도·작동 단면·단위 관계·공간 배치·절차 그림처럼 목적에 따라 다른 구조가 가능하다. 실사도 전신 착용·소재 확대·작업 과정·공간 장면 중 필요한 것을 고른다. 늘 같은 카드 몇 개를 나열하거나 같은 책상 위 소품을 바꾸는 방식에 머물지 않는다.

## 선택 예시 — 고정 규칙 아님

| 독자가 이해할 내용 | 가능한 표현 | 피할 오해 |
|---|---|---|
| 개인정보 유출 확인·신고 순서 | 차분한 디지털 안내, 경로도, 연락처 역할 구분 | 실제 은행 화면·피해 확인 결과·보상 보장처럼 보임 |
| 후드집업 기장·안감·핏 | 착용 화보, 안감 매크로, 실측 항목 도해 | 생성 모델을 필자의 실착 후기나 사이즈 정답으로 제시 |
| 경량패딩 활용·충전재 | 생활/야외 장면, 레이어링 구조, 소재 확대 개념 | 야외 사진을 보온 시험·권장 기온의 증거로 사용 |
| 가습기 방식·청소 | 생활 삽화, 작동 단면, 관리 순서 | 모든 제품이 그림과 같은 내부 설계·분해법이라는 단정 |
| 여행 장소·동선 | 분위기 장면, 위치 관계도, 이동 경로 | 가상 장소를 실제 방문 사진이나 정확한 지도로 제시 |
| 앱의 실제 사용법 | 제공된 실제 화면 또는 공식 자료에 설명 | 생성한 버튼·메뉴를 실제 조작 경로로 안내 |

다른 분위기나 매체가 더 적합하면 다른 선택을 한다. 위 사례의 색상·구도·화풍을 재사용 기본값으로 만들지 않는다.

## 한 글의 일관성과 여러 글의 차별성

- 한 글 안에서는 편집 방향과 정보 역할이 이어지게 한다. 실사와 도해를 함께 써도 각자의 설명 목적과 사실성 경계가 분명하면 된다. 모든 장을 같은 형식으로 만드는 것이 일관성은 아니다.
- 인물이 이어지는 실제 경험·비교 장면에서는 동일 조건을 지킨다. 서로 다른 일반 예시의 모델을 동일인 실착 과정처럼 연결하지 않는다.
- 여러 편에서는 각 글의 브리프를 새로 잡고 전체 계획을 비교한다. 주제가 다른데 이전 글의 장면·매체·정보 배치를 그대로 물려받았다면 이유를 확인하고 필요 없는 반복을 재설계한다.
- 색상·배경·브랜드명·제목만 바꾼 결과는 새로운 연출로 간주하지 않는다. 독자가 얻는 정보에 맞춰 장면, 카메라 거리, 비교 기준 또는 정보 구조를 바꾼다.
- 사용자가 원하는 연재 공통 스타일이나 실제로 유효한 공통 구조는 유지할 수 있다. 반복을 무조건 실패 처리하지 말고 해당 글들에서 그 구조가 필요한 이유를 기록한다. 한 장면을 다른 장면으로 늘려 수량만 채우는 것은 허용하지 않는다.

## 생성 후 검수

개별 이미지를 실제로 보고, 여러 편이면 전체 묶음도 대조한다.

- 제목의 핵심 상황과 인접 문단의 설명이 그림에 대응하는가?
- 선택한 매체·배경·구도·분위기가 이 상황에서 필요한가?
- 각 슬롯이 다른 정보를 더하는가, 같은 레이아웃에 라벨만 바뀌었는가?
- 한글·수치·방향·측정 기준·작동 구조가 문단과 충돌하지 않는가?
- 허구 UI·실물 증거·사용 후기·성능 시험처럼 오해할 요소가 없는가?
- 모바일에서 핵심 피사체와 관계를 읽을 수 있는가?

검수 근거에는 “이미지 존재”나 “고품질” 대신 **어느 장면·라벨·관계를 확인했고 어떤 문단을 보완하는지** 남긴다. 파일 해시가 모두 다르거나 구조 검사기가 통과해도 상황 적합성·다양성이 검증된 것은 아니다. 이는 수동 시각 검수이며 현재 정본 검사기의 자동 판정 항목으로 보고하지 않는다.

상황에 안 맞는 이미지는 배경색만 바꿔 통과시키지 않는다. 문제의 수준이 한글·부품 오류라면 그 요소를, 전체 장면·표현 구조라면 연출 자체를 수정한다. 기존 워크플로의 슬롯당 한 번 보정 제한을 따르고, 재실패 시 미해결로 남긴다. 재제작은 기존 원본을 보존한 새 버전으로 저장하고 변경된 이미지·캡션·정본을 재검수한다.

스킬 업데이트 요청 자체로 이미지 재생성·기존 원고 교체·브라우저 입력·네이버 발행을 실행하지 않는다.
