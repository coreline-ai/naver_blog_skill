# 제목 프레임워크

## 입력 분석

제목 생성 전에 아래 항목을 가능한 범위에서 채운다.

| 항목 | 질문 | 예시 |
|---|---|---|
| 대상 | 무엇에 관한 글인가? | KTX 승차권 |
| 독자 상황 | 독자는 지금 어떤 상태인가? | 출발 전 취소하려는 사람 |
| 행동 의도 | 무엇을 하려는가? | 취소·환불 |
| 결정 변수 | 무엇을 알아야 행동할 수 있는가? | 수수료·환불 기간·출발 전후 차이 |
| 근거 | 제목에 넣을 수 있는 확인된 사실은 무엇인가? | 출발 시점에 따라 조건이 달라짐 |
| 금지 주장 | 아직 확인하지 못한 것은 무엇인가? | 정확한 시간·금액 |

`신청`, `환불`, `예매` 같은 단어는 독자 의도를 드러내는 수단이다. 특정 접미사 `-하기` 자체를 필수 요소로 만들지 않는다.

## 검색형 패턴

검색형은 **명시성**과 **결정 지원성**을 우선한다.

1. 방법형: `대상 + 행동 방법｜순서·준비물·주의사항`
2. 조건형: `대상 + 행동 조건｜대상·기간·제외 기준`
3. 비용형: `대상 + 행동｜수수료·가격·처리 기간`
4. 비교형: `A와 B 비교｜차이·선택 기준`
5. 문제 해결형: `문제 증상 + 해결 방법｜원인·확인 순서`

좋은 검색형은 제목 앞부분만 읽어도 대상과 의도가 드러난다. 키워드 나열 대신 독자가 클릭 후 얻게 될 판단 재료를 붙인다.

## 홈판형 패턴

홈판형은 **자기 관련성**과 **구체적인 변화**를 우선한다.

1. 실수·결과형: `무엇을 놓쳤더니 어떤 문제가 생겼습니다`
2. 기준 변화형: `같은 행동인데 이 조건에서 결과가 달라집니다`
3. 반전형: `당연히 A인 줄 알았는데 실제 기준은 B였습니다`
4. 관찰형: `요즘 특정 상황의 사람들이 먼저 확인하는 것`
5. 목록형: `특정 상황을 겪고 알게 된 판단 기준 N가지`

단, 입력이나 본문에 없는 개인 경험을 만들지 않는다. 근거가 없는 경우에는 중립형으로 바꾼다.

```text
근거 없는 경험형: 출발 직전에 취소했더니 수수료가 두 배였습니다
안전한 중립형: 출발 시점에 따라 KTX 취소 수수료가 달라지는 기준
```

## 혼합형 패턴

혼합형은 `검색 앵커｜홈판 후크` 구조를 기본으로 한다.

```text
KTX 취소 환불방법｜출발 전후 수수료가 달라지는 기준
인터파크 티켓 예매방법｜결제 전에 막히기 쉬운 준비 단계
청년지원금 신청조건｜접수 전에 확인할 제외 기준
```

뒤 절에는 앞 절의 동의어를 반복하지 말고, 실수·차이·조건·비용·결과 중 하나를 추가한다.

## 후보 다양화

후보들은 다음 관점을 나눠 갖게 한다.

- 절차 중심
- 비용 또는 기간 중심
- 자격·조건 중심
- 실수 예방 중심
- 비교·선택 중심
- 경험·변화 중심(근거가 있을 때만)

모든 후보에 숫자를 붙이거나 모든 제목을 `총정리`로 끝내지 않는다.
