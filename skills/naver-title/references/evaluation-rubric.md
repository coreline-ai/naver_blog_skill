# 제목 평가 기준

## 먼저 적용할 통과 조건

아래 항목 중 하나라도 실패하면 표현을 수정한 뒤 비교한다.

- **사실성:** 입력·본문·검증 자료에 없는 수치, 경험, 순위, 권위, 희소성을 만들지 않았다.
- **제목-본문 일치:** 제목에서 약속한 답, 비교, 목록, 결과를 본문이 실제로 제공할 수 있다.
- **비보장성:** 상위 노출, 홈판 선정, 조회수 상승을 확정적으로 말하지 않는다.
- **자연스러움:** 검색어를 기계적으로 반복하거나 조사만 제거한 키워드 나열이 아니다.
- **비기만성:** 궁금증은 만들지만 핵심 대상이나 손익을 속이지 않는다.

## 검색 적합도

다섯 항목을 `높음 / 보통 / 낮음`으로 판단한다.

| 항목 | 높음의 기준 |
|---|---|
| 대상 명확성 | 무엇에 관한 글인지 첫 절에서 식별된다. |
| 의도 일치 | 방법·조건·비교·후기 등 검색 목적이 분명하다. |
| 결정 정보 | 비용·기간·순서·자격·차이 등 클릭 가치가 있다. |
| 전면 배치 | 중요한 대상과 의도가 모호한 후크보다 먼저 나온다. |
| 가독성 | 중복 없이 자연스럽고 모바일에서 빠르게 읽힌다. |

## 홈판 적합도

| 항목 | 높음의 기준 |
|---|---|
| 자기 관련성 | 특정 독자가 자신의 상황으로 인식할 수 있다. |
| 긴장·변화 | 실수, 차이, 결과, 반전 중 하나가 구체적이다. |
| 정보 공백 | 답이 궁금하지만 무엇에 관한 글인지는 알 수 있다. |
| 구체성 | `이것`, `충격` 같은 빈 후크보다 상황과 손익이 보인다. |
| 전달 가능성 | 본문 초반에서 제목의 궁금증을 정직하게 해소할 수 있다. |

## 혼합형 적합도

- 앞 절은 검색 적합도에서 대상·의도가 `높음`이어야 한다.
- 뒤 절은 새로운 결정 변수나 궁금증을 추가해야 한다.
- 두 절이 같은 말을 반복하면 혼합형으로 보지 않는다.
- 길이보다 정보 밀도를 우선하되, 필요 없는 세 번째 절은 제거한다.

## 대표적인 감점 패턴

| 패턴 | 문제 | 개선 방향 |
|---|---|---|
| `KTX 환불 환불방법 취소 수수료 총정리` | 키워드 중복 | 대상·행동·핵심 변수만 남긴다. |
| `이것 모르면 무조건 손해` | 대상·근거 불명 | 어떤 상황에서 어떤 손해인지 밝힌다. |
| `90%가 모르는 신청법` | 근거 없는 수치 | `신청 전에 놓치기 쉬운 조건`으로 바꾼다. |
| `제가 직접 해봤습니다` | 입력에 없는 경험 | 중립형 설명 제목으로 바꾼다. |
| `조회수 보장 제목` | 결과 보장 불가 | 목적 적합도와 검수 결과만 말한다. |

## 최종 추천 방법

숫자 총점으로 정밀함을 가장하지 않는다. 통과 조건을 모두 만족한 후보끼리 목적에 따라 고른다.

- 검색 유입 우선: 대상·의도·결정 정보가 가장 선명한 후보
- 홈판 클릭 우선: 자기 관련성과 변화가 크면서도 사실적인 후보
- 균형형: 검색 앵커가 앞에 있고 뒤 절의 후크가 새 정보를 주는 후보

선정 이유는 한 문장으로 설명한다. 낮은 평가를 받은 후보는 왜 약한지 함께 고친다.
