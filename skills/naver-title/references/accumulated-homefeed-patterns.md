# 축적된 홈판형 패턴 활용

프로젝트에 `skills/moneydaeoebi-homepan/references/title-pattern-matrix.md`가 있으면 해당 소재에 맞는 신호·구조를 우선 검토한다. 해당 파일이 없는 설치 환경에서는 아래 요약과 [제목 프레임워크](title-framework.md)를 사용한다. 이 참고는 패턴 활용이지 R9 전용 50개 출력 워크플로를 자동 호출하는 지시가 아니다.

| 패턴 | 독자가 알아볼 장면과 정보 공백 | 조건 |
|---|---|---|
| 예상과 실제 | A라고 생각하기 쉽지만 B를 먼저 확인 | 본문에서 실제 차이를 설명 |
| 같은 이름·다른 조건 | 비슷한 상품·혜택인데 기준이 달라지는 지점 | 비교 대상과 기준을 명시 |
| 선택 전 확인 | 구매·신청 전 놓치기 쉬운 조건과 다음 행동 | 독자에게 해당하는 상황이어야 함 |
| 결과와 이유 | 확인된 결과 뒤 그 과정·원인을 묻는 구조 | 결과와 원인이 모두 확인돼야 함 |
| 상황별 선택 | 두 상황에서 무엇을 비교해야 하는지 제시 | 본문에 양쪽 선택 기준이 있어야 함 |

사용자가 준 제목은 고정 지시가 없는 한 원안 후보로 남기고 서로 다른 패턴의 대안을 비교한다. 대상·구체 상황·판단 단서를 갖춘 충실한 길이를 우선하되 30~55자는 편집상 참고이며 강제하지 않는다. 기존 사례는 구조적 참고일 뿐 검증된 클릭 성과가 아니다. 실제 크리에이터 통계는 접근·기간·집계가 확인된 경우에만 별도로 사용한다. 확인되지 않은 경험·효과·인기·숫자를 만들지 않는다.
