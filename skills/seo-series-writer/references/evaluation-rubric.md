# 발행 전 원고 검수

원고를 출력하기 전에 아래 기준으로 실제 내용을 확인한다. 문구가 포함됐는지만 보지 말고 독자가 약속된 답을 얻는지 판단한다. 평소 검수 과정을 길게 출력하지 않으며, 요청 시 `확인 / 수정 / 미확인`과 근거를 짧게 제시한다.

| 기준 | 확인할 내용 | 실패 시 조치 |
|---|---|---|
| 완성형 분량 | 게시 본문이 제외 영역을 빼고 3,000자 이상인가? | 부족한 고유 설명·예제·도구를 보강; 반복 문장으로 채우지 않음 |
| 질문 해결 | 제목이 약속한 핵심 질문에 본문이 실제 답하는가? | 제목을 좁히거나 필요한 답을 보완 |
| 주제 고유성 | 핵심 문단이 장소명·제품명·증상명만 바꿔도 성립하는 일반론은 아닌가? | 고유 권역·대상·조건·구분 기준 보강 |
| 회차 차별성 | 인접 글과 다른 범위·판단 기준·실용 자료가 있는가? | 반복 문단을 줄이고 이번 회차의 고유 답 보완 |
| 실용성 | 독자가 무엇을 관찰·변경·확인할지 알 수 있는가? | 조건이 명확한 절차·비교·실습 추가 |
| 실전 산출물 | 경로 예시·증상표·선택표·체크리스트 중 주제에 맞는 도구가 있는가? | 독자가 바로 적용할 한 가지 도구 추가 |
| 사실성과 조건 | 수치·인과·정책·성분·표준의 근거와 적용 범위가 맞는가? | 확인 또는 제한 표현·검토 대기 |
| 경험의 진실성 | 1인칭 경험·실험·성과가 실제 제공 자료에 있는가? | 삭제하거나 명시적 가정으로 전환 |
| 출처 정직성 | 링크를 실제 확인했으며 해당 주장을 뒷받침하는가? | 허구·무관 링크 제거, 미확인 항목 표시 |
| 검색 의도 | 제목·도입부가 독자의 의도를 드러내며 키워드 나열이 아닌가? | 중복 키워드와 과장 제거 |
| 출력 분리 | 관리 코드·진행·메타데이터가 게시 본문과 구분되는가? | 편집자용 영역으로 이동 |
| 회차 일관성 | 완료 목록·재작성·다음 작성 회차·목차상 예고가 정확한가? | 실제 제공 범위로 수정 |
| 비보장성 | 승인·순위·자동 게시·영구 기억을 약속하지 않는가? | 가능한 결과물과 한계로 수정 |
| 프로필 적합성 | 선택한 primary의 필수 흐름과 산출물이 실제 본문에 있는가? | 말투만 바꾸지 말고 구조·실용 자료를 보강 |
| 한계와 예외 | 적용 범위·반례·중단/다음 점검 조건이 있는가? | 독자가 오적용하지 않도록 조건을 추가 |
| 경험 무결성 | 후기·스토리의 사용·방문·실험이 제공 근거와 일치하는가? | 허구 경험 삭제, 가정 표시 또는 프로필 전환 |

평가 결과를 숫자 점수나 승인 확률로 바꾸지 않는다. 3,000자는 제작 하한일 뿐 전문성 점수가 아니다. 형식 검사는 사실 검증·독창성·사이트 심사를 대신하지 못한다.

## 결과 상태

- **원고 검수 완료**: 위 항목을 확인했고 남은 핵심 미확인 사항이 없는 경우. 실제 게시·외부 심사·SEO 성과가 확인됐다는 뜻이 아니다.
- **초안 · 사실 검토 필요**: 완성된 원고는 제공했지만 핵심 출처나 조건 검토가 남은 경우. 편집 메모와 상태의 검토 대기 회차에 기록한다.
- **입력 확인 필요**: 없는 목차·원고·측정 결과 등 없으면 답이 달라지는 정보가 필요한 경우. 최소 정보만 요청하고 해당 회차를 완료로 표시하지 않는다.

검수 근거에는 `도입 2문단`, `소제목 3의 증상표`, `마지막 체크리스트`처럼 실제 위치와 독자가 얻는 답을 함께 적는다. v2 연동에서는 위치, 발견 내용, 연결한 출처를 구조화해 기록한다. “정보성으로 작성함”, “일반론만 사용함”, “수치를 만들지 않음”만으로 질문 해결이나 실용성을 passed 처리하지 않는다. 여러 회차에 같은 포괄적 근거를 복사하지 않는다.

고정된 출처 개수·키워드 밀도로 의미 품질을 판정하지 않는다. 완성형 3,000자 하한은 별도 구조 검사이며, 통과 후에도 위 의미 기준을 모두 확인한다. 수정 후에는 실제 실패한 기준을 다시 확인한다.
