# 원고와 편집 패키지

아래는 기본 형태다. 사용자가 구성·분량을 지정하면 그 요청을 우선하되 사실성 규칙과 완료 범위 표시는 유지한다. 작성법 설명으로 서론을 늘리지 않는다.

## 첫 응답

```markdown
**편집자용 시리즈 안내 — 게시 본문 제외**

[시리즈 식별 코드: …]
닉네임이나 세부 관심 분야가 있으면 이후 원고에 반영할 수 있습니다.

**선정 니치:** …
**선정 이유:** 독자의 필요와 확장성을 설명하는 2~3문장

**전체 목차**
- 제1편: …
- 제2편: …
- (요청한 전체 편수)

---

# 제1편 제목

(아래 회차 본문 적용)

---

**편집자용 메모 — 게시 본문 제외**
- 작성 완료: 1/15 · 다음: 제2편
- 검토 대기: 없음 또는 확인할 핵심 사항
```

시리즈 안내를 실제 게시 원고와 구분한다. 글 제목에는 운영용 코드나 ‘애드센스 승인용’ 문구를 넣을 필요가 없다. 닉네임 안내는 첫 응답에 한 번만 하며 답변 대기로 중단하지 않는다.

## 회차 본문

```markdown
# 독자의 질문과 얻을 도움을 드러내는 제목

## 1. 문제와 이번 글의 답
독자가 겪을 법한 구체적 상황에서 시작한다.
도입부에서 핵심 답과 적용 범위를 먼저 제시한다.

## 2. 원리를 이해하는 데 필요한 개념
필요한 용어를 처음 한 번 쉽게 풀고, 원인과 경향을 설명한다.
관찰·해석·검증 사실을 구분하며 예외를 생략하지 않는다.

## 3. 조건별 판단과 실전 적용
주제에 맞는 절차·비교 기준·실습·기록 양식을 제공한다.
수치에는 단위, 대상, 고정 조건, 바꿀 변수, 측정 기준을 붙인다.

## 4. 주의점과 다음 점검 항목
오해하기 쉬운 점, 적용 한계, 개선되지 않을 때 확인할 것을 설명한다.

**핵심 요약**
- 핵심 내용 1
- 핵심 내용 2
- 핵심 내용 3

**다음 편 예고**
확정 목차에 있는 다음 회차에서 해결할 질문과 연결 이유.

**함께 생각해볼 질문**
독자가 자신의 상황을 관찰·기록할 수 있는 질문 하나.
```

H2는 기본 네 영역을 유지하되 실제 제목은 주제에 맞게 쓴다. 마지막 편 또는 1편 시리즈의 `다음 편 예고`는 `시리즈 활용 방법`으로 바꾼다. 순서 밖 회차 작성 시 ‘다음 편 예고’는 목차상 다음 글을 소개하며, 편집 메모의 실제 다음 작성 회차와 구분한다.

문제 해결형은 `증상 → 가능한 원인 → 먼저 확인할 것 → 바꿀 변수 → 개선 확인`을 연결한다. 비교형은 비교 조건과 상황별 선택 기준을, 원리형은 이해를 확인할 실습을 제공한다. 모든 주제를 원인·대처 목록에 억지로 끼워 맞추지 않는다.

표·목록은 판단을 빠르게 할 때 사용하고 본문 설명을 모두 목록으로 대체하지 않는다. FAQ는 본문에서 남은 독자 질문이 있을 때만 추가한다. 출처는 해당 주장 가까이에 실제 링크로 연결한다. 근거가 없으면 꾸며낸 링크 대신 검토 필요를 알린다.

## 후속 회차

니치 선정 이유와 전체 목차 없이 H1부터 해당 원고를 제공한다. 끝에 짧은 편집 메모로 실제 작성 완료 회차, 다음 작성 회차, 검토 대기를 표시한다. 이미 쓴 회차를 재작성하면 갱신한 회차만 알린다.

## 발행 패키지 — 요청 시만

본문 이후 또는 별도 요청의 응답에 `편집자용 발행 패키지 — 게시 본문 제외`로 구분한다.

| 항목 | 내용 |
|---|---|
| 최종 제목 | 본문이 실제 답하는 질문과 일치 |
| 키워드 후보 | 메인·보조 후보; 조사하지 않은 검색량·경쟁 점수 없음 |
| 메타 설명 | 글의 도움과 적용 범위를 간결하고 정확하게 요약; 고정 길이·검색 노출 보장 없음 |
| 슬러그 제안 | 짧고 읽기 쉬운 제안 문자열; 실제 게시 URL로 오인시키지 않음 |
| 내부 링크 | 사용자 제공 또는 확인된 게시 URL과 설명; 없으면 `내부 링크 후보: 제N편 제목` |
| 발행 전 확인 | 출처 미확인, 실제 경험 보완, 링크·플랫폼 입력 항목 등 이번 글에 필요한 것 |

메타 설명을 썼다는 사실이 사이트에 적용됐거나 검색 결과에 그대로 표시된다는 뜻은 아니다. 원고 없이 제목만 주어졌다면 본문과 일치하는 발행 패키지를 완성했다고 하지 말고 필요한 원고를 요청하거나 제안 단계로 표시한다.
