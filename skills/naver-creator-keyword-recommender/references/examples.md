# 사용 예

## 기본 추천

```text
$naver-creator-keyword-recommender
내 크리에이터 어드바이저에서 최근 완료된 7일을 확인하고,
홈카페 블로그와 직접 관련된 키워드 10개를 추천해줘.
직전 7일과 비교하고 각 키워드의 대표 제목을 1개씩 만들어줘.
본문, 이미지, SmartEditor 작업은 하지 마.
```

결과는 수집 상태, 추천 키워드, 관찰 근거, 주제 적합도, 위험도, 키워드별 대표 제목, 적용 패턴, 글 방향에서 멈춘다. `글 작성은 하지 마`는 본문을 비활성화하지만 제목은 기본 출력한다.

## 키워드만 받기

```text
$naver-creator-keyword-recommender
최근 완료 7일을 직전 7일과 비교해 키워드 10개만 추천해줘.
제목과 본문은 만들지 마.
```

이 요청은 `keywords-only`로 처리하고 메인 유입 패턴 요약은 근거용으로만 남긴다.

## 메인 제목 패턴만 분석

```text
$naver-creator-keyword-recommender
최근 7일 메인 유입 콘텐츠에서 제목 원문을 복사하지 말고
숫자·인용·질문·반전·정보 공백 패턴만 분석해줘.
키워드나 추천 제목은 만들지 마.
```

## 블로그 홈 제목 패턴만 분석

```text
$naver-creator-keyword-recommender
네이버 블로그 홈 1페이지부터 10페이지까지 주요 피드 제목을 확인해
숫자·질문·비교·방법·후기·문제 해결 패턴과 위험 신호를 집계해줘.
원문 제목과 키워드는 출력하지 말고 본문·이미지·SmartEditor 작업도 하지 마.
```

이 요청은 `home-patterns`로 처리한다. 블로그 홈 단어를 검색 키워드로 바꾸거나 제목의 성과를 예측하지 않는다.

## 검색 유입과 블로그 홈 패턴 결합

```text
$naver-creator-keyword-recommender
최근 완료된 7일 검색 유입을 직전 7일과 비교해
내 블로그에 맞는 키워드 10개를 추천해줘.
네이버 블로그 홈 1~10페이지는 제목 원문이 아니라 구조만 분석하고,
각 키워드에 어울리는 안전한 대표 제목을 1개씩 만들어줘.
본문·이미지·SmartEditor 작업은 하지 마.
```

이 요청은 `recommend-with-home`으로 처리한다. 키워드는 검색 유입에서만 선정하고 홈 피드에서는 검수된 패턴만 가져온다.

## 키워드별 제목 후보 3개

```text
$naver-creator-keyword-recommender
최근 7일 추천 키워드를 보여준 다음 내가 하나를 선택하면
선택한 키워드별로 검색형·홈판형·혼합형 제목 후보를 3개씩 만들어줘.
본문은 작성하지 마.
```

`title-candidates`로 처리한다. 검색 유입 키워드와 메인 유입 패턴을 분리하고, 제목 원문 대신 검수된 구조만 `naver-title` 규칙에 전달한다.

## 전체 워크플로

```text
$naver-creator-keyword-recommender
최근 7일 데이터에서 승인용 정보 글에 적합한 주제 하나를 선정하고,
제목 후보와 본문, 이미지 5장을 준비한 뒤 SmartEditor에 임시저장해줘.
공개 발행과 예약 발행은 하지 마.
```

이 요청은 추천 스킬이 모든 기능을 직접 수행한다는 뜻이 아니다. 추천 후 `naver-title`, 기존 작성·이미지 흐름, `naver-smarteditor-drafter` 또는 `naver-series-workflow`의 계약과 검수 게이트를 순서대로 적용한다.

## 부분 수집 응답

```markdown
## 수집 상태
- 추천 기간: 2026-09-05~2026-09-11
- 검색 유입: 7/7일 관찰
- 메인 유입: 6/7일 관찰
- 비즈니스: 서비스 오류로 0/7일
- 상태: partial

비즈니스 데이터가 없으므로 비즈니스 적합도는 평가하지 않았습니다.
검색 유입 키워드 추천은 가능하지만 전체 화면 비교 결과로 해석하면 안 됩니다.
```

## 관련 후보가 없을 때

```markdown
최근 수집 데이터에는 홈카페와 직접 관련된 반복 키워드가 없습니다.
현재 인기 키워드를 억지로 홈카페 주제와 결합하지 않겠습니다.
인접 후보를 별도로 보거나 기존 장기형 주제에서 선택할 수 있습니다.
```
