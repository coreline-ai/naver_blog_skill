# 본문과 출력

## 구성 선택

소재에 맞는 구조 하나를 중심으로 쓴다.

| 구조 | 적합한 소재 |
| --- | --- |
| 타임라인 | 사건 전후와 상태 변화가 핵심일 때 |
| Q&A | 독자의 질문이 명확한 정보형 |
| 비교 | 같은 기준의 A/B, 전후 차이 |
| 결과 선공개 | 결과 뒤의 원인·과정을 설명할 때 |
| 정리 리스트 | 조건·준비물·예외를 빠르게 찾게 할 때 |
| 장면 확대 | 실제 한 장면이나 발언이 중심일 때 |

구조를 기계적으로 순환하거나 직전 글과 다르다는 이유만으로 부적합한 구조를 고르지 않는다.

## 제목 약속 지도

쓰기 전에 내부적으로 정리한다.

```text
제목의 구체 단서:
제목이 숨긴 답:
답을 공개할 위치:
답 이후 제공할 두 번째 가치:
확인할 수 없어 제외할 내용:
```

도입은 제목의 단서를 실제 사실로 다시 세우고 단서 하나를 더한다. 숨긴 답은 도입 끝에서 첫 소제목 사이에 준다. 같은 의문을 글 절반까지 끌지 않는다.

답을 준 뒤에는 다음 중 하나를 제공한다.

- 조건과 예외
- 전후 또는 대안 비교
- 독자가 확인할 다음 행동
- 사건 이후 현재 상태
- 원자료가 아직 밝히지 않은 범위

## 말투

- 친근한 존댓말을 기본으로 하되 사건의 무게에 맞춘다.
- 기사 어미만 `~했어요`로 바꾸지 말고 정보 순서를 독자 기준으로 재구성한다.
- 문단은 보통 1~3문장으로 하고, 각 문단에 새로운 정보나 판단 기준을 둔다.
- `주목할 점은`, `눈길을 끄는데요`, `귀추가 주목됩니다`, `단순히 A가 아니라 B` 같은 상투어를 반복하지 않는다.
- 메타 설명보다 주체와 근거를 직접 쓴다.
- 같은 숫자·날짜·결론을 새 의미 없이 반복하지 않는다.
- 가짜 표정, 날씨, 침묵, 대화, 방문·구매·사용 경험을 만들지 않는다.
- 사망, 질병, 수사, 사고에는 유머와 참여 유도 질문을 쓰지 않는다.

## 소제목

- 장식이 아니라 다음에 추가되는 내용을 알려준다.
- 질문형과 설명형을 섞되 전부 `왜일까?`로 만들지 않는다.
- 단락을 지웠을 때 사라지는 정보가 없다면 합치거나 뺀다.
- 정보형은 대상·핵심 조건을 첫 소제목 안에서 제공한다.

## 마무리

일반론이나 교훈을 반복하지 않는다. 처음 장면을 회수하거나 독자가 확인할 다음 단계로 끝낸다. 가벼운 생활형 글은 답할 수 있는 구체 질문 하나를 선택적으로 사용할 수 있다. `공감 눌러주세요` 같은 반응 강요는 쓰지 않는다.

## 게시용 기본 형식

사용자가 별도 형식을 지정하지 않으면 다음 순서를 쓴다.

```text
제목 한 줄

도입

## 소제목
본문

## 소제목
본문

#해시태그 #5개에서10개
```

`제목:`, `본문:` 라벨은 붙이지 않는다. 조사한 출처는 게시용 원고와 별도의 `근거 메모`에 둔다. 다만 플랫폼이나 사용자가 문장 가까운 인용을 요구하면 그 형식을 따른다.

## 최종 검사

- 제목의 질문에 실제로 답했는가?
- 첫 문단이 제목만 반복하지 않는가?
- 행위자, 시점, 수치, 단위가 제목과 본문에서 같은가?
- 문단마다 새 정보가 있는가?
- 자료 해설자의 관점과 사용자의 경험을 혼동하지 않았는가?
- 확인되지 않은 내용을 자연스러운 문장으로 감추지 않았는가?
