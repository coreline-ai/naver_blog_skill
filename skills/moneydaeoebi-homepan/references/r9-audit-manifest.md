# R9 검사 파일과 매니페스트

이 명세는 50개 규칙을 선언이 아니라 검사 가능한 형태로 남기기 위한 내부 작업 형식이다. 사용자가 원하지 않으면 매니페스트 자체를 대화에 출력하지 않는다.

## 후보 파일

`titles.txt`에는 최종 50개 후보만 한 줄에 하나씩 넣는다. 그룹 제목, TOP5, 추천 이유와 출처 메모는 넣지 않는다. 번호는 생략하거나 `1.`부터 `50.`까지 연속으로 붙일 수 있다.

각 줄의 끝에는 스타터 라벨을 정확히 하나 붙인다.

- 따옴표 실제 발언: `[실제 발언]`
- 따옴표 독자 질문: `[독자 반응]`
- 무따옴표: `[무따옴표-N1]`부터 `[무따옴표-N7]`

필요하면 스타터 라벨 뒤에 `[감정대체]`, `[민감대체]`, `[LEWORD 2번 보강]`, `[신규]` 같은 출처·대체 라벨을 추가할 수 있다.

## 매니페스트 형식

`manifest.json`은 다음 구조를 사용한다. 스타터 ID `S01`부터 `S30`은 [제목 실험실](title-lab.md)의 30종 순서와 같다. `starters` 값에는 해당 스타터로 실제 시험한 원형 후보를 적는다.

TOP5는 서로 다른 5개 그룹에서 골라야 한다. `final`은 TOP5 중 하나여야 하며 `title`은 해당 번호의 후보에서 끝 라벨을 제거한 문장과 글자 하나까지 같아야 한다.

## 실행

```bash
python3 scripts/audit_title_set.py titles.txt \
  --r9 \
  --track feed \
  --manifest manifest.json \
  --strict
```

- 검색형은 `--track search`, 혼합형은 `--track mixed`를 사용한다.
- 사망·질병·범죄 피해·미성년자 소재는 `--sensitive`를 추가한다.
- `--r9`에서는 매니페스트가 필수다.

감사 통과는 형식과 수량을 증명할 뿐 사실성을 증명하지 않는다. 제목에 쓴 수치·발언·현재 상태는 별도의 출처 검사와 제목 관문을 통과해야 한다.
