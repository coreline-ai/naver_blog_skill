# 사실 검증과 안전

## 출처 순서

가능하면 다음 순서로 확인한다.

1. 법령, 정부·기관 공고, 회사 공식 발표, 경기 기록, 당사자 원문 같은 1차 자료
2. 원취재 기사와 전문 데이터베이스
3. 통신사·주요 언론의 교차 보도
4. 포털 요약, 재인용 기사, 커뮤니티, 실시간 화제어 집계

같은 보도자료를 받아쓴 기사 여러 개를 독립된 근거 여러 개로 세지 않는다. 검색 결과 제목이나 스니펫만으로 핵심 주장을 확정하지 않는다.

## 주장 카드

고위험 주장이나 긴 원고는 다음 필드를 내부적으로 사용한다.

```text
주체 / 행동 / 대상:
핵심 주장:
상태: 확인 사실 / 당사자 발언 / 언론 보도 / 추정 / 의견
출처:
사건일 / 보도일 / 시행일 / 확인일:
숫자 / 단위 / 대상 / 조건:
원문의 강도:
제목에서 가능한 표현:
본문에서 밝혀야 할 한계:
```

불분명한 값은 `미확인`으로 둔다. 0이나 `없음`으로 바꾸지 않는다.

## 자주 틀리는 구분

- 발행일 ≠ 사건일
- 검토·예산안·발표·시행·접수·선정·지급은 서로 다른 상태
- 관심·제안·합의·공식 계약은 서로 다른 이적 단계
- 신고·의혹·수사·송치·기소·구형·선고·확정은 서로 다른 법적 단계
- 최대 지원액 ≠ 모두의 지급액
- 정가·호가·평가액 ≠ 실제 지출·실거래·현금
- 회사 매출·부모 재산 ≠ 개인 자산
- 예약·주문·계약·판매는 서로 다른 수치
- 순위 관측일 ≠ 최초 진입일
- 일부 댓글·한 커뮤니티 ≠ 대중 전체
- 화제어 순위 ≠ 사건 사실

`최초`, `유일`, `모두`, `마지막`, `전부`, `몇 년 만`은 비교 범위와 기간을 검증해야 한다.

## 인용

- 실제 문구, 화자, 대상, 앞뒤 문맥을 확인한다.
- 기자의 요약을 당사자 직접 인용으로 바꾸지 않는다.
- 부정어, 조건, 목적을 빼서 뜻을 바꾸지 않는다.
- 원문을 직접 보지 못했다면 `보도에 인용된 발언`이라는 확인 범위를 유지한다.

## 관계·내면·사생활

사진, 동석, SNS 삭제, 불참, 침묵으로 열애·결별·질투·분노·후회·질환을 확정하지 않는다. 당사자 발표와 정황을 분리한다. 공개되지 않은 학교, 거주지, 동선을 교복·거리뷰·사진으로 추론하지 않는다.

살아 있는 미성년자의 외모, 체형, 연애, 사생활을 제목 훅으로 쓰지 않는다. 공식 활동의 경기 기록, 출연, 수상은 사실 범위에서 다룰 수 있다.

## 건강·법률·금융

현재 규정과 개인 사실관계가 결론을 바꾸므로 권위 있는 최신 자료를 확인한다. 일반 정보와 개인 조언을 구분하고, 사진이나 증상 발언만으로 진단하지 않는다. 기관 안내를 판결처럼 표현하지 않는다.

## 두 번의 검증

### 제목 전

제목의 핵심 전제, 최신 상태, 수치·단위, 직접 인용 여부를 확인한다. 거짓인 강한 제목을 먼저 만든 뒤 마지막에 약화시키는 방식은 쓰지 않는다.

### 원고 후

문장마다 근거의 의미와 범위를 유지했는지, 제목과 본문의 주체·시점·숫자가 같은지 확인한다. 오류가 있으면 다음 순서로 고친다.

1. 잘못된 핵심을 특정한다.
2. 확인된 사실 중 여전히 읽을 이유가 있는 재료를 찾는다.
3. 그 재료로 제목을 고친다.
4. 본문도 같은 사건·시점·단위로 맞춘다.
5. 다른 후보에 같은 오류가 퍼졌는지 확인한다.

조회가 높았다는 사실은 오류나 과장을 정당화하지 않는다.
