# 카테고리별 검증 규칙

관련 항목만 읽고 적용한다.

## 연예·방송

- 프로필 나열보다 실제 장면, 발언, 관계 변화가 있을 때만 그 각도를 쓴다.
- 예능 농담을 진단, 고백, 실제 갈등으로 키우지 않는다.
- 작품 속 관계와 배우의 실제 관계를 섞지 않는다.
- 광고·협찬 콘텐츠는 초반에 캠페인 또는 상업적 맥락을 밝힌다.
- 결혼·임신·이혼은 당사자 발표와 정황을 분리한다.

## 사망·투병·사고

- 죽음, 질병, 피해를 정보 공백이나 감정 증폭 장치로 쓰지 않는다.
- R9의 10번 그룹 자리와 5개 수는 유지하되 감정 증폭 대신 고인의 활동·추모의 의미·유족이나 기관의 공식 대응을 앞세우고 `[민감대체]`를 붙인다.
- 따옴표 20개 규칙을 지킬 때도 B형 독자 반응은 죽음·질환·피해의 정체를 묻는 방식으로 만들지 않는다. 확인된 실제 발언이나 존중을 해치지 않는 사실 질문만 허용한다.
- 고인의 활동, 확인된 경위, 유족·기관의 공식 발표를 중심으로 쓴다.
- 유머와 댓글 참여 질문을 생략한다.

## 스포츠

- 예선·본선·결선, 경기일·보도일, 당시·현재 순위를 구분한다.
- 개인 기록과 팀 결과를 혼동하지 않는다.
- 이적은 관심, 접촉, 제안, 합의, 메디컬, 공식 발표 단계를 구분한다.
- 기록 임박 표현은 남은 조건과 비교 범위를 확인한다.

## 자동차·제품·IT

- 신차가, 보조금 적용가, 중고 매물가, 실구매가를 구분한다.
- CLTC, WLTP, EPA, 국내 인증처럼 측정 기준을 함께 쓴다.
- 예약, 사전 주문, 계약, 출고, 판매량을 섞지 않는다.
- 리콜은 결함, 대상, 위험, 조치, 내 제품 확인 방법 순으로 정리한다.
- 이미지로 본 모델·규격·등급을 확정해 최고가를 실제 지출처럼 쓰지 않는다.

## 정책·지원금·금융

- 주체, 대상, 지역, 기간, 조건, 제외 기준, 최대 금액, 신청 방법, 현재 상태를 확인한다.
- 최대 금액과 실제 수령액, 신청 가능과 선정 완료를 구분한다.
- 발표·예고·입법예고·시행을 구분한다.
- 개인의 세금·보험·투자 결론은 최신 공식 자료와 사실관계 없이는 확정하지 않는다.

## 법률·수사·논란

- 피소, 신고, 수사, 송치, 기소, 구형, 선고, 확정판결을 구분한다.
- 당사자 주장, 수사기관 판단, 법원 판단을 분리한다.
- 무죄나 불송치가 상대방의 고의적 허위를 자동 입증한다고 쓰지 않는다.
- 혐의를 사실로 확정하거나 한 장면으로 반성 여부를 판단하지 않는다.

## 건강·뷰티

- 사진으로 질환, 임신, 체중, 시술 여부를 진단하지 않는다.
- 개인 사례와 일반 효능을 구분한다.
- 전후 사진만으로 특정 제품의 인과 효과를 주장하지 않는다.
- 최신 권위 자료가 없는 치료·복용·식단 조언은 만들지 않는다.

## 여행·행사·생활정보

- 과거 후기와 현재 운영 시간, 요금, 주차, 예약 조건을 구분한다.
- 행사 기간이 꽃·단풍의 절정을 보장한다고 쓰지 않는다.
- 시간표를 방문자의 결정 순서로 비교하되 제공되지 않은 교통편·대기시간을 만들지 않는다.
- 일부 매장의 품절을 전국 품절로 확대하지 않는다.

## 실시간 화제어·뉴스

- 집계 서비스, 순위, 확인 시각을 밝힌다.
- 검색어 문구만으로 사건을 재구성하지 않는다.
- 동일 사건의 최신 상태와 원출처를 별도로 확인한다.
- 하나의 키워드가 여러 인물·사건을 뜻하면 확인 전 제목을 확정하지 않는다.
