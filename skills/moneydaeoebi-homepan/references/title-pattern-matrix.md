# 카테고리별 제목 패턴표

이 문서는 30종 스타터를 완성 제목으로 전개할 때 사용할 구조를 고른다. 패턴은 사실을 대신하지 않으며, 현재 소재에 실제로 존재하는 신호와 맞는 것만 사용한다.

## 신호 확인

- `QUOTE`: 확인된 실제 발언
- `NUMBER`: 의미 있는 금액·기간·수량·비율
- `CHANGE`: 이전과 달라진 상태
- `CONTRAST`: 같은 기준에서 확인되는 차이
- `RESULT`: 결과·성과·결정
- `CONFLICT`: 확인된 갈등·논란
- `RELATION`: 실제 또는 작품 속 명확한 관계 변화
- `WHY`: 본문에서 답할 수 있는 이유
- `UNCERTAIN`: 공식 확정 전의 실제 미확정 상태
- `CURRENT`: 지금 확인해야 할 일정·상태
- `CHOICE`: 독자의 선택 기준

한 제목에는 핵심 신호 1~2개만 선명하게 둔다. 현재 사실 → 독자 질문 → 편집 각도 → 패턴 순서로 고른다.
