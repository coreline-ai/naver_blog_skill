# 사례에서 추출한 편집 경로

과거 사례는 성과를 보장하는 공식이 아니라 각도를 찾기 위한 질문 모음이다. 소재의 사실과 맞는 경로 1~2개만 고른다.

## 빠른 경로표 P01~P24

피드형 제목은 현재 소재와 맞는 경로 1~2개를 먼저 고른다. 경로가 사실 신호와 맞지 않으면 억지로 적용하지 않는다.

| 경로 | 독자 관심 | 살릴 재료 | 브리지 |
| --- | --- | --- | --- |
| P01 | 비용은 해결됐지만 절차가 불편함 | 연락·허락·대기·선택권 중 실제 막힌 것 | B2 |
| P02 | 구매 전후 판단이 달라짐 | 처음 선택, 이후 행동, 판단이 바뀐 이유 | B3 |
| P03 | 구매 뒤 더 끌리는 선택지가 나옴 | 시점·제품·선택에서 생긴 실제 차이 | B1 |
| P04 | 원하는 생활과 유지 부담의 차이 | 로망, 관리 과업, 감당할 조건 | B3 |
| P05 | 나·친구·가족이 떠오르는 장면 | 알아볼 만한 구체 행동과 대조 | B6 |
| P06 | 내가 되고 싶은 모습 | 태도·생활의 구체 기준 | B3 |
| P07 | 보여주고 싶은 따뜻한 순간 | 짧은 실제 장면과 확인된 반응 | B6 |
| P08 | 누군가에게 건네고 싶은 말 | 관계의 구체 장면과 조심스러운 기준 | B6 |
| P09 | 금액·인원·관계가 충돌함 | 한 장면 안의 실제 선택과 양쪽 조건 | B3 |
| P10 | 장소에 따라 판단이 달라짐 | 허용 범위를 바꾸는 장소·타인 영향 | B3 |
| P11 | 익숙한 기대와 다른 선택 | 역할·사람·선택의 예상 밖 조합 | B1 |
| P12 | 감상하거나 따라 할 디테일 | 눈에 보이는 조합·제품·사용 장면 | B4 |
| P13 | 같은 대상의 다른 쓰임·결과 | 같은 기준으로 비교 가능한 구성 | B1 |
| P14 | 기회 뒤 실제로 한 일 | 선택, 구체 행동, 다음 상태 | B5 |
| P15 | 성공 뒤 남은 유지 과제 | 처음 목표와 이후 조건의 차이 | B5 |
| P16 | 원하던 계획을 막는 조건 | 희망, 확인된 규칙, 가능한 대안 | B2 |
| P17 | 시한 때문에 선택지가 달라짐 | 날짜보다 닫히는 선택지 | B2 |
| P18 | 실패가 다음 시행착오를 줄임 | 대기·동선·실패 이유·다음 시도 | B2 |
| P19 | 나에게 해당하는 답이 가치 | 대상, 답, 조건과 계산 | B2 |
| P20 | 커 보이는 숫자를 분해함 | 총액·단가·현금·대출·소유 구분 | B5 |
| P21 | 경고를 실제 판단 기준으로 바꿈 | 주장, 적용 조건, 반대 상황, 문서 | B3 |
| P22 | 단서를 쌓은 뒤 결과를 회수함 | 새 단서, 확인 과정, 판정 | B5 |
| P23 | 첫 답 다음에 새 질문이 남음 | 첫 답, 실제 적용, 두 번째 보상 | B5 |
| P24 | 같은 사건의 서로 다른 질문 | 사실 상태, 비교, 공식 대응의 분리 | B5 |

이 표는 과거 사례의 인물·수치·결과를 재사용하기 위한 자료가 아니다. `독자 관심 → 현재 사실 재료 → 브리지`만 가져온다.

## B1 비교

같은 기준으로 전후, A와 B, 기대와 실제를 비교한다.

- 무엇이 얼마나 달라졌는가?
- 가격, 시간, 거리, 조건 중 독자의 선택을 바꾸는 값은 무엇인가?
- 비교 기준이 서로 같은가?

## B2 생활 연결

뉴스의 발표를 독자의 실제 행동으로 바꾼다.

- 이 사실 때문에 독자가 오늘 확인할 것은 무엇인가?
- 신청, 이동, 구매, 취소, 예약 과정에서 어느 단계가 달라지는가?
- 최대 혜택과 실제 적용 조건이 어떻게 다른가?

## B3 판단 질문

단순 찬반 대신 선택 기준을 만든다.

- 누구에게 유리하거나 불리한가?
- 어떤 조건에서 결론이 바뀌는가?
- 아직 공개되지 않은 정보는 무엇인가?

## B4 디테일 확대

사진, 시간표, 계약 조항, 제품 사양처럼 실제로 확인된 작은 단서 하나를 확대한다.

- 이 단서가 전체 사건에서 왜 중요한가?
- 눈에 보이는 것과 해석을 구분했는가?
- 작은 단서에서 확인할 수 없는 내면·원인까지 확장하지 않았는가?

## B5 정리

복잡한 상태, 일정, 조건을 독자의 순서로 재배열한다.

- 발표 순서가 아니라 결정 순서로 설명했는가?
- 신청·선정·지급, 관심·제안·합의·발표처럼 상태를 나눴는가?
- 첫 단계에서 대상 여부를 알 수 있는가?

## B6 관계 장면

두 사람이나 조직의 실제 발언·행동·역할 변화가 있을 때 쓴다.

- 실제 관계와 방송·작품 속 관계를 구분했는가?
- 함께 등장했다는 사실을 친분·갈등·연애의 증거로 키우지 않았는가?
- 발언의 화자, 대상, 문맥이 맞는가?

## 선택 규칙

- 정보가 세 덩어리면 세 덩어리만 쓴다. 정해진 소제목 수를 채우지 않는다.
- 같은 사건에서 제목을 여러 개 만들 때는 숫자만 바꾸지 말고 독자 질문을 달리한다.
- 원문에 없는 강한 결론을 추가하는 대신 실제로 확인된 다른 장면이나 조건을 찾는다.
- 과거 사례의 사람, 수치, 결과를 새 글의 사실로 옮기지 않는다.
