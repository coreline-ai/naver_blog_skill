이 문서는 기존 네이버 블로그 스킬의 제목 전략을 보완하는 후속 작업 범위를 고정한다. 완료된 이미지 개발·실검증 기록은 보존한다. 계획 작성 이후 사용자가 구현을 명시 요청했으며, 아래 체크박스를 실제 구현·자체 검수 결과에 따라 갱신한다.

## 개발 목적

‘무엇부터 담을까요?’처럼 궁금증만 제시하는 제목에서 벗어나, 검색 대상과 독자가 읽을 이유를 구체적으로 보여준다. 기존 naver-title을 글 작성 흐름에 연결해 검색형·홈판형·혼합형을 목적에 따라 선택하고, 유형 미지정 시 혼합형을 기본으로 사용한다.

## 개발 범위

- 기존 naver-title의 프레임워크·평가 기준을 재사용하고 새 제목 생성 엔진이나 독립 스킬을 만들지 않는다.
- 통합 글쓰기에서는 유형 미지정 시 검색형 3개·홈판형 3개·혼합형 3개를 내부 비교하고 혼합형 최종 제목 1개를 선정한다. 명시 유형·개수·고정 제목은 우선한다.
- 독립 naver-title의 일반 기본값 5/5/3과 단축 호출 4/3/3은 유지한다. 통합 경로는 3/3/3을 명시적으로 전달하며 독립 기본값을 바꾸지 않는다.
- 개인 문체 프로필의 제목 규칙 3곳과 루트 작성 지침을 정합화한다. 본문 말투·문장형 소제목 선호·CTA·사실성 규칙은 유지한다.
- 자료 확인·본문 초안 → 제목 후보/검수/선정 → 제목과 본문 최종화 → 이미지 슬롯·프롬프트·생성 순서로 연결한다. 제목 선정 때문에 추가 승인 질문을 기본으로 넣지 않는다.
- 제목별 근거·선정 이유는 편집 메모로 분리한다. 일반 글 완성 결과에는 확정 제목을 사용하고, 후보 전체는 사용자가 요청할 때만 보여준다.
- 제목 확정 시점·기존 파일 보존·이미지 계획의 최신성·독립 호출 회귀를 검증하고 사용 예시와 결과를 기록한다.
