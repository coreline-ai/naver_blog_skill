## 입력·출력 계약

### 입력

- 트리거: `$seo-series-writer`, `SEO 시리즈 글`, `애드센스 승인용 시리즈 글`, `정보성 블로그 15편 시리즈`처럼 시리즈 기획·작성 의도가 명확한 요청.
- 비트리거: `네이버 제목 ...`, 문체 인터뷰, 단순 단일 글 수정, 이미지 생성. 기존 스킬의 요청을 가로채지 않는다.
- 기본값: 한국어, 초보~초중급 독자, 15편, 첫 응답은 목차와 제1편, Markdown.
- 선택값: 니치, 전체 목차, 편수, 회차/범위, 닉네임, 문체, 실제 경험·측정자료, 게시 URL, 발행 패키지 요청.
- 원고 분량은 약 2,000~3,000자를 편집 출발점으로 제안할 수 있으나 절대 규칙이나 SEO 기준으로 강제하지 않는다.
- 니치 미지정 시 자동 선정하고 가정을 짧게 알린다. 제공된 니치·목차·편수는 우선 적용한다.

### 출력

1. 첫 응답: 관리용 코드·선택 안내 → 니치·선정 이유 → 전체 목차 → 제1편 완성 원고.
2. 회차 원고: H1 제목 → 번호형 H2 네 영역(문제와 답 / 원리 / 적용 / 한계) → 핵심 요약 → 다음 편 예고 → 관찰 질문.
3. 후속 요청: 해당 회차만 작성하고 전체 목차와 선정 이유를 반복하지 않는다. 마지막 편은 예고 대신 시리즈 활용법을 제시한다.
4. 발행 패키지 요청 시: 제목·키워드 후보·메타 설명·슬러그·실제 URL 기반 내부 링크 또는 링크 후보·확인 필요 사항을 편집자용으로 분리한다.
5. 관리용 코드와 진행 요약은 게시 본문과 구분한다. 사실 출처는 해당 주장과 연결하고 관리 메타데이터와 혼동하지 않는다.
