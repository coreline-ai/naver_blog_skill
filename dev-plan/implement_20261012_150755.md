## 개발 목적

기존 네이버 블로그 스킬에서 `주제 + 정보 슬라이드/카드뉴스형 N장 + 완성`이라는 한 번의 사용자 요청을 원고 작성·정확한 N개 슬롯 설계·실제 이미지 생성·시각 QA·본문 삽입으로 연결한다. 사용자에게 입력 원고나 슬롯 JSON을 먼저 준비하도록 요구하지 않는다.

## 개발 범위

- 루트 스킬의 한국어 발동 설명과 기존 스킬 UI 메타데이터, 주제 기반 요청 처리 reference를 보완한다.
