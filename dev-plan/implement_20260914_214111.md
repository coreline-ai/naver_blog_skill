## 개발 목적

`naver-series/v2`의 준비 완료 판정, 대표 이미지 위치 검사, 캡션 제외 방식이 문서화된 계약과 실제 실행에서 동일하게 동작하도록 보완한다.

- 준비 보고서의 요약 플래그가 실제 정본·검수 산출물과 다르면 실패시킨다.
- `cover` 역할뿐 아니라 실제 대표 이미지가 H1 직후 첫 콘텐츠 블록인지 확인한다.
- 캡션은 문자열 일치가 아니라 합성 구조와 블록 식별자를 기준으로 본문 글자 수에서 제외한다.
- 기존 `naver-series/v1`, `compose_article_text()` 호출 규약, SmartEditor 실행 이력은 유지한다.

- 이미지 합성 API는 기존 `(text, count)` 계약을 유지하면서 검증된 ordered slots를 반환하는 추가 API를 제공한다.

- cover는 역할 선언과 함께 canonical post의 첫 콘텐츠 block 배치를 통과해야 한다.
- prepare와 snapshot 조회가 같은 v2 상태 파생 함수를 사용하고 report·metrics·preflight·정본 불일치를 `CORRUPT_SNAPSHOT`으로 거부한다.
