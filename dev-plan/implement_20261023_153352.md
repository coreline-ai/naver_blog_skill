## 개발 목적

정보 슬라이드형을 유지하면서 대표 이미지는 1:1, 본문 이미지는 16:9로 지정할 수 있도록 요청 → 프롬프트 → 실제 파일 검사 → 문답형 합성 경로를 보완한다. 비율 미지정 시 기존 4:5 동작은 유지한다.

## 개발 범위

- 이미지 요청 v1에 선택 필드 `aspect_ratios: {"cover":"1:1","inline":"16:9"}`를 추가한다. 허용 비율은 이번 요구와 기존 기본값인 `1:1`, `16:9`, `4:5`로 한정한다. 역할 하나만 지정하면 다른 정보 슬라이드는 기존 4:5를 사용한다.
- 공통 도우미에서 역할별 비율을 검증하고 한국어·영어 생성 프롬프트와 계획 항목에 반영한다. 정보 슬라이드의 표지도 계속 카드뉴스이며 일반형으로 우회하지 않는다.
- 완성 검사와 문답형 파일 등록에서 실제 픽셀 비율을 동일한 함수로 검사한다. 기존 4:5의 세로 환산 오차 1픽셀 이하·상대 오차 0.1% 이하 기준을 일반화한다.
- 문답형의 선택 옵션 `aspect_ratios`를 초기 요청·옵션 변경·요청 조립·자산 재검수에 연결한다. 미지정 세션에 새 필수 질문을 추가하지 않는다.
- 루트·문답형·시리즈 지침, 이미지 계약, README와 기능 가이드를 현재 구현에 맞춰 갱신한다.
